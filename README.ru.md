# SLAYhomepage

[English version](README.md)

Стартовый экран для [SillyTavern](https://github.com/SillyTavern/SillyTavern). Вместо пустого окна показывает недавних ботов: одним кликом можно вернуться в разговор, начать новый или открыть все чаты. 30 тем, из них 19 в стиле игр. Интерфейс на русском и английском.

## Установка

1. В таверне откройте **Расширения → Установить расширение**.
2. Вставьте адрес и подтвердите:

   ```
   https://github.com/wewwaistyping/SLAYhomepage
   ```

3. Обновите страницу.

Проверено на SillyTavern 1.19.0, на компьютере и на телефоне.

Если у вас стоит расширение LandingPage, удалять его не нужно: пока открыт SLAYhomepage, его экран скрыт.

## Как пользоваться

Экран появляется сам, когда ни один чат не открыт. Сам он чаты не открывает, только по вашему нажатию.

- **Продолжить** открывает последний чат с выбранным ботом.
- **Новый чат** начинает разговор заново.
- **Все чаты** показывает список чатов бота.
- Ботов можно листать стрелками ← →, Enter продолжает чат. На телефоне работает свайп.

Настройки: **Расширения → SLAYhomepage → Темы, картинки и остальное…**

Можно поставить одну тему или включить режим **«Сюрприз при запуске»**: каждый раз откроется случайная тема из избранного. Маленькая кнопка в углу экрана листает темы, не заходя в настройки.

Ненужные темы можно скрыть значком с глазом на карточке: они пропадут из списка, из кнопки в углу и из «Сюрприза». Вернуть их можно в фильтре **«Скрытые»**.

Цифры на игровых экранах (уровни, дружба, характеристики) считаются из ваших чатов: сколько сообщений, сколько чатов, как давно вы разговаривали.

## Картинки в полный рост

Игровые темы выглядят лучше всего с картинкой персонажа в полный рост, желательно PNG с прозрачным фоном. Без неё экран покажет обычный аватар. Тема «Покемоны» всегда показывает аватар.

Картинка задаётся на вкладке **Картинки**: выберите бота и перетащите файл. Одну картинку можно сразу поставить другим версиям этого персонажа.

Карточка и аватар бота при этом не меняются. Файл сохраняется в `user/files`, перед загрузкой он уменьшается до 1600 px по высоте и сжимается в WebP. В настройках хранится только ссылка. Если убрать картинку, файл останется в `user/files`.

Для групповых чатов своя картинка пока не поддерживается.

## Настройки

| Настройка | Что делает |
|---|---|
| Показывать стартовый экран | Включает и выключает расширение |
| Кнопка «сменить тему» на экране | Кнопка в углу со стрелками |
| Прятать верхнее меню | Меню таверны скрыто и выезжает, когда мышь у верхнего края (на телефоне — по тапу у края). Экран занимает всю высоту. По умолчанию выключено |
| Язык интерфейса | Как в таверне, русский или английский. «Как в таверне» — русский для русской таверны, для остальных английский |
| Сколько недавних ботов показывать | От 3 до 20 |
| Показывать групповые чаты | Группы попадают в список вместе с ботами |
| Скрытые боты | Эти боты не появятся на экране, даже если чат свежий |

## Что важно знать

- **Шрифты грузятся с Google Fonts.** Это единственные внешние запросы расширения. Без интернета экраны будут работать с запасными шрифтами.
- **Качество картинок.** По умолчанию таверна делает миниатюры 96×144, для большого экрана этого мало. В таком случае SLAYhomepage показывает оригинальные карточки ботов на экране, отдельное расширение не нужно. Если карточки тяжёлые, можно поднять `thumbnails.dimensions.avatar` в `config.yaml`, и экран будет брать миниатюры.
- **Батарея.** Через 20 секунд без касаний анимации засыпают и просыпаются от любого движения. Когда открыт чат, экран полностью выгружен и ничего не крутит.
- **Темы таверны.** Расширение рисует экран поверх таверны и не меняет вашу тему оформления.
- **Переводы.** Строки лежат в `lang/en.json`, ключи — русский текст. Чтобы добавить язык, скопируйте файл в `lang/<код>.json` и переведите значения.
