# SLAYhomepage

[Русская версия](README.ru.md)

A start screen for [SillyTavern](https://github.com/SillyTavern/SillyTavern). Instead of an empty window it shows your recent bots: one click takes you back into a conversation, starts a new one or opens all your chats. 30 themes, 19 of them styled after video games. The interface is available in English and Russian.

## Installation

1. In SillyTavern, open **Extensions → Install extension**.
2. Paste this address and confirm:

   ```
   https://github.com/wewwaistyping/SLAYhomepage
   ```

3. Reload the page.

Tested on SillyTavern 1.19.0, on desktop and on a phone.

If you have the LandingPage extension installed, there's no need to remove it: its screen stays hidden while SLAYhomepage is open.

## How to use it

The screen appears on its own when no chat is open. It never opens a chat by itself, only when you click.

- **Continue** opens the latest chat with the selected bot.
- **New chat** starts a fresh conversation.
- **All chats** shows the bot's chat list.
- Flip through bots with the ← → keys, Enter continues the chat. On a phone, swipe.

Settings: **Extensions → SLAYhomepage → Themes, pictures and more…**

You can set one theme or turn on **Surprise on launch**, which opens a random favorite every time. A small button in the corner of the screen flips through themes without opening the settings.

Themes you don't need can be hidden with the eye icon on the card: they disappear from the list, the corner button and Surprise. The **Hidden** filter brings them back.

The numbers on game screens (levels, friendship, stats) come from your chats: how many messages, how many chats, how long ago you last talked.

## Full-height pictures

Game themes look best with a full-height picture of the character, ideally a PNG with a transparent background. Without one, the screen shows the regular avatar. The Pokémon theme always uses the avatar.

Set a picture on the **Pictures** tab: pick a bot and drop the file. You can apply the same picture to other versions of that character right away.

The bot's card and avatar stay the same. The file is saved to `user/files`, scaled down to 1600 px in height and compressed to WebP before upload. The settings keep only a link. If you remove a picture, the file stays in `user/files`.

Custom pictures aren't supported for group chats yet.

## Settings

| Setting | What it does |
|---|---|
| Show the start screen | Turns the extension on and off |
| "Change theme" button on screen | The corner button with arrows |
| Hide the top menu | The Tavern menu stays hidden and slides out when the mouse reaches the top edge (on a phone, tap the edge). The screen takes the full height. Off by default |
| Interface language | Same as Tavern, Russian or English. "Same as Tavern" means Russian for a Russian Tavern and English for everything else |
| How many recent bots to show | From 3 to 20 |
| Show group chats | Groups join the list with the bots |
| Hidden bots | These bots never appear on the screen, even if the chat is fresh |

## Good to know

- **Fonts load from Google Fonts.** These are the extension's only external requests. Without internet, the screens fall back to other fonts.
- **Battery.** After 20 seconds without input, animations go to sleep and wake on any movement. When a chat is open, the screen is fully unloaded and runs nothing.
- **Tavern themes.** The extension draws its screen on top of the Tavern and doesn't change your UI theme.
- **Translations.** Strings live in `lang/en.json`, with the Russian text as keys. To add a language, copy that file to `lang/<code>.json` and translate the values.
